# Observer v1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local, Docker-packaged code-observability dashboard: run one container, mount a repo, click tabs that run best-in-class analyzers and render diagrams, with artifacts written to the repo's `obs-data/` for a git-tracked architecture history.

**Architecture:** A single Go binary (`observer`) serves an embedded static web UI and a small REST API. It loads a per-repo `obs-data/observer.yaml` manifest of **tabs** (plugins). Each tab's **Update** runs a shell command (a built-in `observer gen …` subcommand for native analyses, or a bundled external tool like `go-callvis`) and writes one artifact into `obs-data/`. The binary ships inside a polyglot Docker image that bundles every external tool, so the host needs only Docker. Diagrams render client-side (mermaid.js, viz.js, marked — all vendored, no build step).

**Tech Stack:** Go 1.26 (stdlib `net/http`, `embed`, `os/exec`), vanilla JS + vendored mermaid.js/viz.js/marked, Docker (multi-stage), goreleaser, GitHub Actions + `act`.

## Revisions (from plan review — THESE TAKE PRECEDENCE over any conflicting task text below)

- **R1 (self-exec PATH):** In `runner.Run`, resolve `os.Executable()`; if a command's first token is `observer`, replace it with the absolute path to the running binary before `sh -c`. Without this, native `gen` tabs fail in host mode (no `observer` on PATH).
- **R2 (output convention):** Native generators take an explicit `--out <path>` (and `gen er` also `--dbml-out <path>`) and **write the file themselves** — no stdout capture. Manifest commands: `observer gen changes --base main --out obs-data/changes.md`; `observer gen er --migrations <dir> --out obs-data/er.mmd --dbml-out obs-data/er.dbml`; `observer gen hotspots --out obs-data/hotspots.json`; `observer gen overview --out obs-data/index.md`; `observer gen godeps --out obs-data/godeps.dot`. External tools write via their own flags/redirect.
- **R3 (nested modules):** Add `Dir string \`yaml:"dir,omitempty"\`` to `manifest.Tab`. `DefaultTabs` walks for nested `go.mod`/`package.json` (depth ≤3, skip `node_modules`,`vendor`) and sets `Dir`. Runner sets `cmd.Dir = filepath.Join(repo, tab.Dir)`. (servicePlus Go module is at `services/api/`.)
- **R4 (bind local only):** `serve` defaults `--addr 127.0.0.1`; Task 10 wrapper uses `-p 127.0.0.1:7979:7979`. Never bind all interfaces (POST runs shell).
- **R5 (Docker UID/cache/fonts):** Dockerfile: `RUN mkdir -p /go && chmod 777 /go`; `ENV GOPATH=/go GOCACHE=/go/cache GOMODCACHE=/go/pkg/mod HOME=/tmp`; `RUN git config --system --add safe.directory '*'`; install `fontconfig fonts-dejavu-core` (else graphviz SVGs render tofu).
- **R6 (honest trust model):** Reword the runner comment: it executes repo-defined commands (trust model = running the repo's Makefile; local-only). Docker mode enforces source safety by mounting source read-only + `obs-data` writable (Task 10).
- **R7 (`_index.json`):** Schema `{"tabs": {"<name>": Artifact}}`. Server holds a `sync.Mutex`; `GET /api/project` reads it (tolerate missing); writes are atomic (temp file + rename). Single canonical name `_index.json` (fix DESIGN §5 wording).
- **R8 (path safety + verify):** `manifest.Parse` rejects `Output`/`Dir` that are absolute or contain `..`. After the command, `os.Stat` the declared output (error if absent — tools can exit 0 without producing it). Server sets Content-Type by renderer (`svg`→`image/svg+xml`, `markdown`→`text/markdown`, `json`→`application/json`).
- **R9 (dependency-cruiser):** Dockerfile `npm i -g dependency-cruiser`; manifest command `depcruise --no-config --output-type dot <frontend-src> > obs-data/web-deps.dot`.
- **R10 (ER rendering):** `gen er` emits BOTH `er.mmd` (mermaid `erDiagram`, renderer `mermaid`) and `er.dbml` (snapshot for v2). Renderer `mermaid` added to the UI. **Drop** the JS DBML→mermaid mapper (double-parse).
- **R11 (YAGNI trims):** **code-maat deferred to v2** (avoids a ~200 MB JRE in the image; the native `hotspots` tab already gives churn + change-coupling). **graphify** tab = a user-supplied `command` (Babak provides it), marked optional; it may use network/LLM, so it is exempt from the strict-offline claim and NOT a blocker for v1.
- **R12 (Overview):** Add `gen overview` → `obs-data/index.md` (freshness + tab/artifact inventory from `_index.json`). It's the default landing tab.
- **R13 (CLI/init):** `cmd/observer` subcommands = `serve | gen | init | doctor | version`. Default go-callvis command omits `-focus`; pin go-callvis to a tagged version (not `@latest`) in the Dockerfile.
- **R14 (wrapper/edge):** Wrapper drops `-it` (gate on `[ -t 1 ]`). `gen changes` handles "no merge-base" gracefully (note it, fall back to the whole history).
- **R15 (CSRF):** `POST /api/*` requires header `X-Observer: 1`; the UI sends it; server rejects POSTs without it (blocks drive-by `POST localhost:7979/api/update` from any webpage).

```go
// Package manifest defines the per-repo observer.yaml schema (the tabs/plugins).
package manifest

import (
	"fmt"

	"gopkg.in/yaml.v3"
)

type Kind string

const (
	KindGenerator Kind = "generator" // command -> artifact file -> rendered inline
	KindService   Kind = "service"   // v2: start a sidecar, iframe its URL
	KindLink      Kind = "link"      // v2: external deep link
)

type Tab struct {
	Name     string   `yaml:"name"`
	Kind     Kind     `yaml:"kind"`
	Command  string   `yaml:"command"`           // generator
	Output   string   `yaml:"output"`            // generator: file under obs-data/
	Renderer string   `yaml:"renderer"`          // markdown|svg|dbml|graph|table
	Requires []string `yaml:"requires,omitempty"`// external tools needed
	URL      string   `yaml:"url,omitempty"`     // service/link
	Start    string   `yaml:"start,omitempty"`   // service
}

type Project struct {
	Project string `yaml:"project"`
	Tabs    []Tab  `yaml:"tabs"`
}

func Parse(b []byte) (*Project, error) {
	var p Project
	if err := yaml.Unmarshal(b, &p); err != nil {
		return nil, fmt.Errorf("parse manifest: %w", err)
	}
	for i, t := range p.Tabs {
		switch t.Kind {
		case KindGenerator, KindService, KindLink:
		default:
			return nil, fmt.Errorf("tab %d (%q): unknown kind %q", i, t.Name, t.Kind)
		}
		if t.Name == "" {
			return nil, fmt.Errorf("tab %d: name is required", i)
		}
	}
	return &p, nil
}
```

```go
// Package gitmeta reports repo freshness: branch, HEAD, dirty, and the
// merge-base against a base branch (for the "changes since" view).
package gitmeta

import (
	"os/exec"
	"strings"
)

type Meta struct {
	Branch    string
	Head      string
	MergeBase string
	Dirty     bool
}

func git(dir string, args ...string) (string, error) {
	c := exec.Command("git", args...)
	c.Dir = dir
	out, err := c.Output()
	return strings.TrimSpace(string(out)), err
}

func Collect(dir, base string) (Meta, error) {
	var m Meta
	m.Branch, _ = git(dir, "rev-parse", "--abbrev-ref", "HEAD")
	head, err := git(dir, "rev-parse", "HEAD")
	if err != nil {
		return m, err
	}
	m.Head = head
	m.MergeBase, _ = git(dir, "merge-base", base, "HEAD")
	status, _ := git(dir, "status", "--porcelain")
	m.Dirty = status != ""
	return m, nil
}
```

```go
// Package runner executes a tab's generator command inside the repo, writes its
// artifact under obs-data/, and records freshness. It NEVER writes outside obs-data/.
package runner

import (
	"context"
	"fmt"
	"os"
	"os/exec"
	"path/filepath"
	"time"

	"github.com/taikuri-infra/observer/internal/gitmeta"
	"github.com/taikuri-infra/observer/internal/manifest"
)

type Artifact struct {
	Tab         string `json:"tab"`
	Path        string `json:"path"` // relative to repo, under obs-data/
	Renderer    string `json:"renderer"`
	GeneratedAt string `json:"generated_at"`
	Head        string `json:"head"`
	Branch      string `json:"branch"`
	Err         string `json:"error,omitempty"`
}

const outDir = "obs-data"

func Run(ctx context.Context, repo, base string, t manifest.Tab, now time.Time) (Artifact, error) {
	if err := os.MkdirAll(filepath.Join(repo, outDir), 0o755); err != nil {
		return Artifact{}, err
	}
	meta, _ := gitmeta.Collect(repo, base)
	a := Artifact{Tab: t.Name, Path: filepath.Join(outDir, t.Output), Renderer: t.Renderer,
		GeneratedAt: now.UTC().Format(time.RFC3339), Head: meta.Head, Branch: meta.Branch}
	cctx, cancel := context.WithTimeout(ctx, 5*time.Minute)
	defer cancel()
	cmd := exec.CommandContext(cctx, "sh", "-c", t.Command)
	cmd.Dir = repo
	if out, err := cmd.CombinedOutput(); err != nil {
		a.Err = fmt.Sprintf("%v: %s", err, out)
		return a, err
	}
	return a, nil
}
```
